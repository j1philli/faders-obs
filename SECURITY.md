# Security

Please report security problems privately, not in a public issue:

- **GitHub:** [Report a vulnerability](https://github.com/j1philli/faders-obs/security/advisories/new) (Security tab → Report a vulnerability)
- **Email:** hello@faders.tv

Include what you found, how to reproduce it, and the plugin version. We'll reply within a few days and keep you posted until it's fixed.

Release installers are built from `main` by CI. Only download them from this repository's [Releases](https://github.com/j1philli/faders-obs/releases) page or [faders.tv](https://faders.tv/streamers/).
